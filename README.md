# 1. Introduction

Environmental sustainability has become one of the most important challenges facing the modern world.

Carbon emissions, excessive energy consumption, transportation pollution, waste generation, and inefficient resource management contribute significantly to environmental degradation and climate change.

Although people and organizations increasingly recognize these challenges, they often lack a unified platform to measure their environmental impact and identify practical ways to improve it.

**EcoTrack AI addresses this challenge through an intelligent, data-driven sustainability ecosystem.**

The platform enables users to:

- Monitor their carbon footprint.
- Understand their environmental impact.
- Receive AI-powered sustainability recommendations.
- Analyze daily, weekly, and monthly sustainability performance.
- Set and monitor environmental goals.
- Participate in environmental challenges.
- Generate sustainability and ESG reports.
- Understand potential environmental risks.
- Make informed decisions that support a sustainable future.

EcoTrack AI aims to make sustainability measurable, understandable, accessible, and actionable.

# 2. Problem Statement

Current sustainability practices face several challenges.

### 2.1 Lack of Environmental Awareness

Many individuals do not understand how everyday activities contribute to carbon emissions.

### 2.2 Fragmented Sustainability Tools

Carbon tracking, energy monitoring, ESG reporting, and environmental awareness tools are often separated across different applications.

### 2.3 Limited Personalized Guidance

People need recommendations based on their activities, habits, and environmental performance rather than generic sustainability suggestions.

### 2.4 Difficulty Measuring Progress

Without consistent monitoring and analytics, it becomes difficult to understand whether sustainability initiatives are producing meaningful improvements.

### 2.5 Limited Community Participation

Environmental initiatives often struggle to maintain engagement because people lack interactive challenges, recognition, and collaborative participation.

### 2.6 Complex ESG Reporting

Organizations need structured sustainability information to understand environmental, social, and governance performance.

# 3. Our Solution

EcoTrack AI provides an integrated platform that connects environmental data, AI-powered guidance, analytics, and sustainability engagement.

The system transforms everyday activity information into understandable environmental insights.

# 9. Carbon Calculation Methodology

Carbon footprint tracking uses activity quantities and emission factors.

The general calculation model is:

**Carbon Emissions = Activity Quantity × Emission Factor**

For example:

If an activity produces an estimated 0.2 kg CO₂e per unit and the recorded activity quantity is 10 units:

10 × 0.2 = 2 kg CO₂e

This is an illustrative calculation, not a universal emission factor.

Actual calculations depend on the activity category, unit, and configured emission factors.

The platform stores the calculated emissions in kilograms of CO₂e.

# 12. Database Architecture

EcoTrack AI uses Supabase and PostgreSQL for persistent data storage.

The project includes database migrations and generated TypeScript database types.

Important database entities include:

| Table | Purpose |
|---|---|
| profiles | User profile and Eco Points |
| carbon_entries | Carbon activity records |
| goals | Personal sustainability goals |
| challenges | Available green challenges |
| user_challenges | User participation and progress |
| community_posts | Community publications |
| post_comments | Community comments |
| post_likes | Community likes |
| achievements | User achievement records |

The database also uses relationships between users, carbon entries, goals, and challenges.

### Row Level Security

Supabase Row Level Security helps restrict access to user-specific information.

For example:

- Users can manage their own carbon entries.
- Users can manage their own goals.
- Users can manage their challenge progress.
- Community posts have defined access policies.
- Achievement records have restricted user access.

# 15. Installation and Setup

Follow these instructions to run EcoTrack AI locally.

### Prerequisites

Install the following:

- Node.js (compatible with the installed Vite and TanStack Start versions).
- npm.
- Git.
- A Supabase project.
- Required AI gateway credentials if using AI-powered features.

### Clone the repository

```bash
git clone https://github.com/navaneeth2805/Ecotrack.Ai.git
```

Navigate into the project:

```bash
cd Ecotrack.Ai
```

### Install dependencies

```bash
npm install
```

This installs the packages specified in `package.json`.

### Configure environment variables

Create a `.env` file in the project root.

Add the required Supabase configuration:

```env
SUPABASE_URL=your_supabase_project_url
SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key

VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

Configure the AI gateway credential using the exact environment variable expected by the AI integration.

Never commit real credentials to GitHub.

### Database setup

1. Create a Supabase project.
2. Configure the Supabase URL and publishable key.
3. Apply the SQL migrations in the `supabase/migrations/` directory.
4. Configure authentication providers.
5. Verify database access policies.
